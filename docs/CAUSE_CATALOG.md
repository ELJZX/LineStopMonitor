# Справочник причин остановки

Единственное место редактирования причин — `data/CauseCatalog.kt`. UI строит
диалог выбора автоматически из этого объекта.

## Структура

```
Категория → Пункт (item) → Причина (reason)
```

- Код причины = `номер пункта * 10 + номер причины`.
- Номера причин внутри пункта: `1..3`; код `...9` — «Другая причина»
  (оператор вводит текст вручную).
- Максимальный код — `129`, влезает в 16 бит и пишется в ПЛК (`D100`).
- Полный путь причины (`causePath`) = `«Категория / Пункт / Причина»`,
  показывается в истории и журнале.

## API справочника

- `CauseCatalog.categories` — дерево для диалога выбора.
- `find(code)` → `Path(category, item, reason)`.
- `reasonTitle(code)` — короткое название.
- `path(code)` — полный путь для истории.
- `isOther(code)` — является ли причина «Другой причиной» (нужен текст).
