# Документация Line Stop Monitor

Система контроля остановок производственной линии на базе контроллера
**Delta DVP12SE11R** и Android-планшета. Планшет читает состояние линии с ПЛК по
**Modbus TCP**, фиксирует аварии, заставляет оператора указать причину и хранит
историю случав в локальной базе SQLite.

Документация составлена по фактическому коду репозитория (ветка `docs`).
Актуальный Changelog и целевые версии — в [`../CHANGELOG.md`](../CHANGELOG.md).

## Ключевые факты

- Авария — **уровневый** сигнал: 24 В на входе `X0`, пока линия стоит; пропадает
  при запуске линии. Начало аварии определяется по фронту `D0 0→1`, конец — по
  спаду `D0 1→0`.
- Опрос ПЛК — каждые **200 мс** (`LineStopViewModel.POLL_MS`).
- Modbus-адрес регистра `Dn` = `0x1000 + n`, порт `502`, Unit ID `1`,
  IP по умолчанию `172.16.29.150`.
- Логика аварий вынесена в чистый класс `domain/AlarmEngine.kt` без зависимостей
  от Android и ПЛК — она полностью покрыта unit-тестами.
- Причина выбирается в три шага: **категория → пункт → причина** (см.
  [`CAUSE_CATALOG.md`](CAUSE_CATALOG.md)).
