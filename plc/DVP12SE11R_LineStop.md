# Программа контроллера DVP12SE11R

ПЛК: **Delta DVP12SE11R** (8 входов X0…X7, 4 выхода Y0…Y3, Ethernet).

## 1. Принцип работы

Сигнал аварии — **уровневый**:

* линия в аварии → на входе `X0` **постоянные 24 В**;
* линию запустили → сигнал **пропадает** (`X0 = 0`).

Приложение показывает диалог выбора причины в момент **исчезновения** сигнала
и подставляет туда период аварии (начало, конец, длительность).

## 2. Подключение

| Клемма | Сигнал |
|--------|--------|
| X0 | АВАРИЯ линии: +24 В, пока линия в аварии; 0 В — когда линия работает |
| Y0 | (опционально) лампа/сирена «авария» |
| S/S | общий входов: `+24V` (sink) или `0V` (source) — по монтажу |

> Выходы у DVP12SE11R — только `Y0…Y3`. Обращение к `Y5` вызовет ошибку.

## 3. Программа (ладдер, 5 сетей)

### Сеть 1. Сброс при старте ПЛК
```
M1002 ──[ MOV K0 D0 ]
      ──[ MOV K0 D1 ]
```
`M1002` — импульс первого скана после перехода в `RUN`.

### Сеть 2. Авария
```
X0    ──[ Y0 ]
      ──[ MOV K1 D0 ]
```
Пока `X0 = 1`: `D0 = 1` (авария), горит `Y0`.

### Сеть 3. Линия работает
```
X0/   ──[ MOV K0 D0 ]
```
Когда сигнал пропал: `D0 = 0`.

### Сеть 4. Счётчик запусков
```
X0↓   ──[ INC D1 ]
```
По спаду `X0` (линию запустили) — `D1 + 1`.

### Сеть 5. Квитирование причины от планшета (обязательная!)
```
D101 = K1 ──[ MOV D100 D5 ]
          ──[ INCP D4 ]
          ──[ MOV K0 D101 ]
          ──[ MOV K0 D100 ]
```
Планшет при выборе причины пишет `D100 = код` и `D101 = 1`.
ПЛК запоминает код в `D5`, увеличивает `D4` и сбрасывает флаги.

### Сеть 6 (необязательно). Длительность аварии
```
M1012↑ ── X0 ──[ INCP D6 ]        ; M1012 — импульс 100 мс
X0↑ ──[ MOV K0 D6 ]
X0↓ ──[ MOV D6 D7 ]──[ MOV K0 D6 ]
```
Без неё приложение считает длительность по своим часам (точность ~0.2 с).

## 4. Карта регистров

Полностью — в [`REGISTER_MAP.md`](REGISTER_MAP.md). Кратко:

| Регистр | Смысл |
|---------|-------|
| D0 | 1 = авария, 0 = работа |
| D1 | счётчик запусков |
| D4 | счётчик квитирований |
| D5 | код последней причины |
| D100 / D101 | причина и запрос квитирования от планшета |

Modbus-адрес `Dn` = `0x1000 + n`, порт 502, Unit ID 1.

## 5. Загрузка в ПЛК (ISPSoft)

1. **ISPSoft + COMMGR** установлены; COMMGR запущен.
2. `File → New` → серия **DVP**, модель **DVP12SE11R**.
3. Ввести сети из раздела 3 (контакты — `A`/`B`, инструкции — по имени).
4. `ПЛК → Компилировать` — без ошибок.
5. **COMMGR**: `Add` → тип **Ethernet** → IP `172.16.29.150`, порт `502` → `Start`.
6. ISPSoft: `Tools → Communication Setting` → выбрать драйвер.
7. ПЛК в `STOP` → `ПЛК → Загрузить` → галочка **Программа** → `Пуск`.
8. `ПЛК → Пуск`.

## 6. Проверка

```powershell
py -3 simulator/plc_monitor.py --host 172.16.29.150
```

- Подайте 24 В на `X0` → `D0=1`.
- Снимите сигнал → `D0=0`, `D1` +1.
- На планшете выберите причину → `D4` +1, `D5` = код причины.

## 7. Проверка без железа

Эмулятор `simulator/plc_sim.py` повторяет ровно эту логику.
Сигнал поднимается/снимается записью в `D200` (`1` / `2`) или командами
`a` / `r` в консоли эмулятора. См. `simulator/README.md`.
