# Карта регистров DVP12SE11R ↔ Android

Соответствует ладдер-программе, загруженной в контроллер (см. `DVP12SE11R_LineStop.md`).

Сигнал аварии — **уровневый**: постоянные 24 В на `X0`, пока линия в аварии.
Как только линию запустили — сигнал пропадает. Приложение показывает диалог
выбора причины по **спаду** сигнала и подставляет период аварии.

Контроллер работает как **Modbus TCP slave** (порт **502**).
Регистры данных `D` доступны как holding registers с базовым адресом **0x1000**:

```
Modbus-адрес = 0x1000 + N   (N — номер регистра D)
```

| Регистр | Modbus-адрес | R/W | Назначение |
|---------|--------------|-----|------------|
| D0      | 0x1000 (4096)| R   | Состояние сигнала аварии: `0` = линия работает, `1` = авария |
| D1      | 0x1001 (4097)| R   | Счётчик запусков (инкремент по спаду X0) |
| D4      | 0x1004 (4100)| R   | Счётчик квитирований (инкремент по `D101 = 1`) |
| D5      | 0x1005 (4101)| R   | Код последней подтверждённой причины |
| D100    | 0x1064 (4196)| W   | Код причины от Android (1..10, 99 = другая) |
| D101    | 0x1065 (4197)| W   | Флаг квитирования: Android пишет `1`, ПЛК сбрасывает в `0` |

## Программа ПЛК (ладдер)

```
M1002 ──[ MOV K0 D0 ]
      ──[ MOV K0 D1 ]          ; сброс при старте ПЛК

X0    ──[ Y0 ]
      ──[ MOV K1 D0 ]          ; авария: D0 = 1

X0/   ──[ MOV K0 D0 ]          ; линия работает: D0 = 0

X0↓   ──[ INC D1 ]             ; счётчик запусков

D101 = K1 ──[ MOV D100 D5 ]
          ──[ INCP D4 ]
          ──[ MOV K0 D101 ]
          ──[ MOV K0 D100 ]    ; квитирование причины от планшета
```

## Протокол

```
X0: 0 -> 1 (появились 24 В)      ПЛК: D0 = 1
                                 Android: начало аварии, время начала, статус "АВАРИЯ"

X0: 1 -> 0 (линию запустили)     ПЛК: D0 = 0, INC D1
                                 Android: конец аварии + длительность,
                                          показывает диалог выбора причины

Android: D100 = код, D101 = 1    ПЛК: D5 = D100, INC D4, D101 = 0, D100 = 0
                                 Android: случай закрыт выбранной причиной
```

Если диалог закрыли без причины — случай остаётся активным на главном экране
до тех пор, пока оператор не укажет причину.

## Примечания

* Длительность аварии приложение считает по своим часам (от момента `D0: 0→1`
  до `D0: 1→0`) с точностью ~0.2 с (период опроса).
* Если планшет перезапустился во время аварии, случай создаётся заново
  с текущего момента — начало аварии восстановить нельзя (ПЛК не измеряет
  длительность). При необходимости можно добавить в ПЛК счётчик времени
  (`M1012` → `INCP D6`, по спаду `MOV D6 D7`) и включить его в приложение.
* `D0…D199` — не энергонезависимые: после снятия питания счётчики обнуляются.
* Modbus TCP на DVP-SE работает по порту 502 «из коробки». `Unit ID` приложения = 1.
