# Эмулятор ПЛК и тесты

Папка содержит отладочный стенд, который позволяет проверить всю логику
системы **без реального контроллера**.

| Файл | Назначение |
|------|------------|
| `plc_sim.py` | Modbus TCP-эмулятор DVP12SE11R с той же картой регистров и логикой |
| `app_logic.py` | Python-порт автомата Android-приложения (`LineStopViewModel.kt`) |
| `test_handshake.py` | Интеграционные тесты протокола «авария → запуск → причина → квит» |

## Запуск эмулятора вручную

```powershell
py -3 simulator/plc_sim.py --host 0.0.0.0 --port 502
```

При старте эмулятор печатает список IP этого ПК — один из них нужно
вписать в приложении (Настройки → IP / Порт).

В консоли:

* `a` + Enter — **поднять сигнал аварии** (X0 = 1, постоянные 24 В);
* `r` + Enter — **снять сигнал** (линию запустили, X0 = 0);
* `d` + Enter — дамп регистров;
* `q` + Enter — выход.

Если stdin не терминал (запуск из IDE/скрипта) — эмулятор не выходит,
а продолжает работать в фоне; остановить можно `Ctrl+C`.

## Тест-хук эмулятора (D200)

Запись в регистр `D200` (Modbus-адрес `0x10C8`) имитирует сигнал на входе ПЛК:

* `D200 = 1` — поднять аварию (`X0 = 1`);
* `D200 = 2` — снять сигнал / запуск линии (`X0 = 0`).

Удобно для автотестов и удалённой отладки, когда нет доступа к консоли эмулятора:

```python
from app_logic import ModbusTcpClient
c = ModbusTcpClient("127.0.0.1", 502)
c.connect()
c.write_single_register(0x1000 + 200, 1)   # авария
c.write_single_register(0x1000 + 200, 2)   # запуск линии
```

## Запуск тестов

```powershell
py -3 -m unittest discover -s simulator -p "test_*.py" -v
```

Ожидаемый результат — `OK`, 11 тестов:

1. стартовое состояние «ОК»;
2. авария создаёт активный случай;
3. снятие сигнала показывает диалог с периодом аварии (длительность из ПЛК);
4. выбор причины квитирует ПЛК;
5. закрытый диалог не закрывает аварию;
6. «Другая причина» с текстом;
7. две аварии до квитирования — два независимых случая;
8. переподключение во время аварии восстанавливает время начала по D6;
9. пропущенная авария восстанавливается по длительности D7 + показывается диалог;
10. самый первый запуск приложения не создаёт ложную аварию;
11. обычное переподключение не создаёт дубликат.
